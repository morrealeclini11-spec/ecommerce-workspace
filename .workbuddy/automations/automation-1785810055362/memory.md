# 每日新闻自动更新（跨境电商）— 执行记录

## 稳定流程（后续沿用）
1. `date "+%Y-%m-%d %H:%M"` 取当天日期。
2. WebSearch 抓六国（美/英/西/意/法/德）跨境电商新闻，用 `query_keyword_groups` 一次覆盖多角度，3 次并行调用即可覆盖全部国家 + 平台/消费补充。
3. 用 Python 脚本 `C:\tmp\build_news.py` 生成 24 条新闻 + 27 条趋势，写 `/tmp/news.json`、`/tmp/trends.json`。
4. 用 `C:\tmp\push_gitee.py` 推送 Gitee（in-linz/ecommerce-data，data/ 目录，master 分支）。
5. 结果副本落到工作区 `data/news.json`、`data/trends.json`，再 present_files。

## 环境坑（重要）
- Windows 上 Git Bash 的 `/tmp` 与 Python 的 `/tmp` 解析不同。统一做法：先 `mkdir -p /c/tmp`，Python 用托管解释器
  `C:/Users/HFD/.workbuddy/binaries/python/versions/3.13.12/python.exe` 运行，`/tmp/x.json` 会落到 `C:\tmp\x.json`，前后一致。
